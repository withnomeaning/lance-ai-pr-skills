# 汽车品牌传播宣传雷区参考

> 供 copy-lens-review 在审核汽车品牌广告、社媒文案、发布会话术、经销商物料及相关品牌传播文案时调用。
> 依据：《广告法》《反不正当竞争法》《消费者权益保护法》《汽车销售管理办法》及近年汽车行业舆情案例整理。
> 最后更新：2026年8月

---

## 一、法规红线（硬性禁止）

### 《广告法》第九条（绝对化用语）

不得使用：
- 「国家级」「最高级」「最佳」「第一」「唯一」「顶级」「极致」「完美」「无可挑剔」
- 变体同样违规：「最智能的车」「史上最强续航」「地表最快」

### 《广告法》第二十八条（虚假或引人误解的宣传）

不得：
- 虚构性能、配置、续航、油耗、排放等级数据
- 使用非量产配置、非标配功能作为广告主画面而未标注
- 「全系标配」实际仅高配/选装才有
- 宣传自动驾驶能力但实为 L2 辅助驾驶
- 续航里程标注未说明测试工况（CLTC/NEDC/WLTP），或使用理想工况替代实际可用里程

### 《反不正当竞争法》第十一条（商业诋毁）

不得：
- 指名贬低竞品品牌、车型
- 暗示竞品不安全、不可靠
- 「某品牌电车自燃率是我们三倍」——无权威数据不得使用
- 拆车对比视频中刻意突出竞品缺陷、隐瞒自产缺陷

### 《汽车销售管理办法》

- 不得强制捆绑保险、金融、装饰
- 宣传的金融方案必须明确利率、手续费、期限
- 「0首付」「0利率」需标注具体条件和限制

## 二、安全与智能驾驶声称雷区

### 绝对禁止

| 类型 | 典型违规表述 |
|------|-------------|
| 绝对安全声称 | 「绝对安全」「零风险」「永不自燃」「100%安全」 |
| 自动驾驶等级夸大 | 将 L2/L2+ 称为「自动驾驶」「无人驾驶」 |
| 事故零承诺 | 「永远不会发生碰撞」「绝对不会失控」 |
| 电池安全绝对化 | 「绝对不起火」「永不爆炸」「彻底杜绝自燃」 |

### 功能声称边界

智能驾驶相关表述必须严格按 SAE 分级和工信部准入要求：

- L2 及以下：只能称「驾驶辅助」「智能辅助驾驶」，**不得使用「自动」字样**
- L3：须注明「有条件自动驾驶」，明确 ODD（运行设计域）
- L4/L5：未经工信部准入不得宣传
- 「解放双手」「开车不用管」「可以睡觉」——**一律禁止**
- 「零接管」「全程无接管」——需有路测数据和 ODD 说明

### AEB/碰撞安全

- 「全速域 AEB」「静止车辆 120km/h 刹停」——须注明测试条件，非适用全场景
- 碰撞测试成绩须标注测试机构、标准版本、具体车型配置
- 「五星安全」仅限 C-NCAP/C-IASI 等权威机构公开成绩，不得自封

### 审核触发词

`自动驾驶` `无人驾驶` `零接管` `解放双手` `绝对安全` `永不自燃` `不会失控` `可以睡觉` `放心交给车` `零事故`

## 三、性能与续航声称雷区

### 续航

- CLTC 续航不得暗示为实际续航，须标注或注明「基于 CLTC 工况测试」
- 「实测续航比官标更长」须注明测试条件（气温、路况、载重、空调状态）
- 冬季续航不得使用「不惧寒冬」「冬天也不打折」等无数据支持表述
- 充电速度（30%-80% X 分钟）须注明充电桩功率、环境温度

### 动力性能

- 零百加速须注明测试条件（气温、路面、电量、轮胎状态）
- 「赛道级」「超跑级」须有圈速/性能数据支撑
- 马力/扭矩标注动力形式（综合最大功率 / 电机峰值功率）

### 审核触发词

`工况续航` `实际续航` `真续航` `不打折` `不惧寒冬` `超跑级` `赛道级` `永磁同步` `800V` `超充`

---

## 四、价格宣传雷区

### 合规要求

- 标注的价格必须明确是「指导价」还是「到手价」还是「起售价」
- 金融方案须注明首付比例、月供、期限、利率、尾款
- 「限时优惠」须标明起止时间
- 「综合优惠」须拆分为现金优惠、金融贴息、置换补贴、权益折现

### 高频翻车叙事

| 模式 | 说明 |
|------|------|
| 价格误导 | 「XX万开回家」——不含购置税/保险/上牌 |
| 权益缩水 | 「首任车主终身质保」但条款含多项排除 |
| 降价维权 | 刚上市即降价，早期车主被割韭菜舆情 |
| 捆绑销售 | 「提车必须买保险」「强制加装潢」 |

### 审核触发词

`仅售` `低至` `不到XX万` `0首付` `0利率` `免费` `送` `终身质保` `限时` `限量`

## 五、竞品对比雷区

### 红线

- 不得直接贬低竞品（指名或可识别暗示）
- 对比数据必须有可查证来源（第三方机构公开发布、同时期、同配置）
- 不得选择性对比（只比己方优势项目，隐藏劣势）
- 「碾压」「吊打」「秒杀」「完爆」——一律不得使用
- 拆车对比、碰撞对比：须完整呈现，不得断章取义

### 易翻车场景

- 发布会竞品对比表格：数据选择性引用最易被截图打脸
- KOL/媒体的「客观对比」实为合作内容：品牌承担连带责任
- 「比XX安全」「比XX省油」——即使数据真实，基调已落商业诋毁争议区

## 六、环保与 ESG 声称雷区

- 「零排放」「零碳」「碳中和」须标注核算边界和抵消方式
- 「绿色」「环保」「可持续」须有可查证的认证、报告或第三方背书
- 电动车不得暗示「对环境完全无害」——电池生产和回收仍有碳足迹
- 供应链 ESG：不得宣传「绿色供应链」而无供应商审计数据

---

## 七、经销商话术连带风险

品牌对经销商对外话术承担监管责任：

- 经销商在直播/短视频中的承诺（价格、配置、交付时间、权益）可被认定为品牌承诺
- 经销商对比竞品/贬低竞品的话术，品牌承担连带责任
- 「厂家补贴」「厂家特批价」等暗示品牌直接让利的表述须有书面依据

### 审核触发词

`厂家补贴` `厂家直销` `厂家特批` `比4S店便宜` `经理特批价`

## 八、高频翻车叙事模式

### 模式一：智驾宣传越界
把 L2 辅助驾驶包装成「自动驾驶」，出事故后被追溯为虚假宣传。近年最高危雷区。

### 模式二：续航数字游戏
CLTC 840km 实际 500km，车主实测「打对折」截图疯传。

### 模式三：降价割韭菜
上市三个月降 3 万，老车主拉横幅维权。「早买早享受，晚买享折扣」口碑崩塌。

### 模式四：配置文字游戏
「全系标配」实为高配专享。车主提车发现「货不对版」，短视频维权传播极快。

### 模式五：交付跳票
「XX月交付」反复延期，准车主集体投诉，订单退订潮。

### 模式六：自燃/失控事故沉默
车辆起火或智驾失控后品牌失声，舆论从「事故原因待查」升级为「品牌无担当」。

### 模式七：环保人设翻车
一边喊「零碳出行」，一边被曝供应链排放造假或碳积分买卖，人设反噬。

## 九、审核操作指引

**第一步：行业识别**
判断是乘用车 / 商用车 / 新能源 / 燃油车 / 新势力 / 传统车企，适用边界和风险点不同。

**第二步：法规扫描**
对照第一节，标记绝对化、虚假宣传、商业诋毁类表述。重点查智驾话术和价格口径。

**第三步：性能声称核对**
续航、加速、充电时间、智驾能力是否能回落到可查证数据（工信部申报、第三方测试、用户手册）。

**第四步：竞品对比审查**
如有竞品对比内容，逐条核验数据来源、时效性、是否选择性引用。

**第五步：价格口径审查**
价格数字是否有前缀（指导价/起售价）和排除项标注，金融方案条件和限制是否完整。

**第六步：截图传播模拟**
提取最夸张的一句 + 配置表/价格表/交付承诺，想象车主群、汽车论坛、短视频评论区的叙事。

**第七步：多视角复核**
准车主、老车主、竞品 PR、汽车媒体、监管至少五视角。

## 十、与通用审核的衔接

汽车文案除本节外，仍须走完整 copy-lens-review 流程。

**Hard Stop 叠加（汽车行业语境）**：

- 智驾能力夸大（L2宣称为自动驾驶）→ 不得「通过」
- 续航/能耗数据无测试工况标注 → 不得「通过」
- 指名贬低竞品或暗示竞品不安全 → 不得「通过」
- 价格口径模糊、金融方案条件不完整 → 不得「通过」
- 出现「绝对安全」「永不自燃」等绝对化安全声称 → **风险较高，建议重写**
