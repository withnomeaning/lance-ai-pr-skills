# AI 公关技能包

把公关行业的判断逻辑、风险意识、执行流程，编译成 AI 可重复调用的 Skill 文件。

## 构成

**5 个专项分析 + 1 个最终取舍：**

| Skill | 作用 |
| --- | --- |
| `judgment-hub` 判断中枢 | 最终取舍：拍板「该做什么、不做什么、为什么」 |
| `hot-public-opinion-analysis` 热点舆情研判 | 把外部热点转成业务判断（是否成势 / 实质 / 走势 / 业务启示） |
| `media-narrative-analysis` 媒体叙事拆解 | 拆一篇稿子替谁说话、想让人信什么、对本方有没有影响 |
| `pr-contingency-plan` 风险预案 | 上线前风险摸排：风险地图 + 官方口径 + 动作建议 |
| `copy-lens-review` 文案公共语境审查 | 文案上线前预检，输出通过 / 修改后可用 / 建议重写 |
| `press-release` 新闻通稿 | 十类通稿起草与改稿，党央媒 / 综合媒体硬新闻风格 |

## 协作逻辑

具体任务先走专项 Skill，专项分析完后由判断中枢做综合取舍。

## 使用

这些是 Claude Code 的 Skill，把整个目录放入 `~/.claude/skills/` 即可被调用。
