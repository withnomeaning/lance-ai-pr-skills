# 汽车新闻通稿类型卡

> 本文件在稿件主类型为汽车行业相关时读取。读取后必须同时执行 `writing-rules.md`。本文件只规定类型识别、小类结构、完整稿准入和类型失败条件，不重复通用写作规则。

## 触发条件

主线是"发布了什么车/技术/服务，谁能用，带来什么变化"。适用于新车上市、车展活动、OTA升级、技术发布、品牌战略合作、交付里程碑。

与相邻类型的边界：
- 安全事故/召回/定价争议回应 → 归 `auto-crisis-response.md`
- 主线依附数据报告（销量、市占率）→ 归全年回顾类（`year-review.md`）
- 主线是公益/ESG/环保行动 → 归 `pet-welfare.md`（暂时借用，未来可扩）

## 细分小类路由

必须从以下四个小类中选择一个：

### 小类一：新车上市

**适用**：全新车型发布、改款上市、新增动力形式/配置版本。

**标题公式**：品牌 + 车型名 + 上市/发布 + 核心变化（动力/续航/价格/定位）

**标题示例**：
- XX品牌全新XX车型正式上市，CLTC续航达XXX公里
- XX品牌XX改款上市，全系标配智驾辅助系统
- XX品牌推出XX纯电版，起售价XX万元

**写作结构公式**：
使用场景/用户需求 → 上市动作 → 车型定位与核心参数 → 解决什么出行需求 → 交付时间与渠道。导语第一句写上市动作、车型名称、定位；正文先写目标用户和出行场景，再写核心产品力（不堆配置表），然后写价格区间和购买渠道；结尾收在交付时间和下一步。

**小类失败条件**：
- 写成配置表罗列，没有使用场景和用户画像
- 只写技术参数不写这对用户意味着什么
- 价格口径模糊（无指导价/起售价标注）

---

### 小类二：车展/品牌活动

**适用**：车展亮相、品牌发布会、试驾活动、用户活动、技术日。

**标题公式**：品牌 + 活动地点/场景 + 核心动作 + 发布内容/展示亮点

**标题示例**：
- XX品牌亮相XX车展，首秀XX概念车与全新平台
- XX品牌举办年度用户日，发布充电网络升级计划
- XX品牌在XX举办技术日，发布新一代电池技术

**写作结构公式**：
活动时间地点 → 发布了什么 → 展台/现场亮点 → 品牌战略含义 → 后续动作。导语第一句写时间、地点、活动名称、核心发布内容；正文先写最重磅的发布或展示，再写现场反应或行业关注，然后写品牌战略层面的含义；结尾收在下一站动作或市场意义。

**小类失败条件**：
- 写成活动流程记录（先XX后XX再XX）
- 只写场面热闹不写发布内容实质
- 没有战略含义，纯活动通稿

---

### 小类三：技术/OTA升级

**适用**：智能驾驶能力升级、OTA推送、电池/电驱技术突破、平台/架构发布。

**标题公式**：品牌 + 技术名称 + 升级/发布 + 能力变化 + 覆盖范围

**标题示例**：
- XX品牌推送XX版本OTA升级，城市智驾覆盖XX城
- XX品牌发布全新XX电驱平台，效率提升XX%
- XX品牌XX电池技术突破，充电速度提升XX%

**写作结构公式**：
技术升级了什么 → 用户得到什么能力变化 → 技术原理（一句话即可）→ 覆盖车型/推送节奏 → 行业意义。导语第一句写升级动作、技术名称、核心变化；正文先写用户侧的能力变化（不是技术参数），再写实现原理（控制在一段内），然后写覆盖范围和推送时间；结尾收在行业对比或后续迭代计划。

**小类失败条件**：
- 写成技术白皮书，满篇参数没有用户价值
- 智驾能力夸大（L2写成自动驾驶）
- 覆盖范围模糊（不写哪些车型/什么时候推送）

---

### 小类四：战略合作/渠道扩展

**适用**：品牌与科技公司/能源企业/经销商集团合作、海外市场进入、充电网络共建。

**标题公式**：合作双方 + 合作动作 + 合作内容 + 覆盖范围/受益对象

**标题示例**：
- XX品牌与XX科技达成战略合作，共建智能座舱生态
- XX品牌进入XX市场，首批XX家门店开业
- XX品牌与XX能源签约，共建XXX座超充站

**写作结构公式**：
合作结果 → 双方分工 → 覆盖范围 → 用户/行业获得什么 → 后续合作安排。导语第一句写合作双方、合作动作、合作内容；正文先写合作已形成的具体结果，再写双方各自提供什么，然后写车主/行业侧的变化；结尾写下一步计划。

**小类失败条件**：
- 只写战略意义不写具体合作内容
- 合作分工含糊（"共同推动""深度合作"）
- 没有覆盖范围和时间节点

---

## 完整稿准入

完整稿至少满足以下 6 项中的 4 项：
- 发布主体（品牌/车型/技术名称）
- 核心动作（上市/发布/升级/合作）
- 使用对象或受益群体
- 核心变化（参数/价格/能力/覆盖）
- 时间节点（上市时间/交付时间/推送时间）
- 渠道或覆盖范围

缺少三项以上，不得写完整稿。

---

## 类型失败条件

命中任一项，必须先修改或追问：
- 正文未按本小类写作结构公式顺序推进，视为结构失败
- 只写配置/参数/技术，不写使用场景和用户价值
- 智驾话术越界（L2宣称为自动驾驶/无人驾驶）
- 价格口径不完整（无标注指导价/起售价/不含XX）
- 交付时间模糊（不写具体月份或季度而写"即将""年内"）
- 写成产品说明书、技术白皮书、活动流程或促销海报

---

## 汽车稿特有风险检查点（交付前逐条核对）

1. **配置描述**：是否为量产配置？是否有"全系标配实际为选装"？
2. **价格口径**：是否标注了指导价/起售价？金融方案条件和限制是否完整？
3. **交付时间**：是否明确到月/季？是否存在"XX月交付"但历史跳票风险？
4. **智驾话术**：是否严格按SAE分级？L2绝对不能出现"自动"字样
5. **续航数据**：是否标注测试工况（CLTC/NEDC/WLTP）？
6. **竞品对比**：是否存在指名/暗示对比？数据来源是否可查证？
